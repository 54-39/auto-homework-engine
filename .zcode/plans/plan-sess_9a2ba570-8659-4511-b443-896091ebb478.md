# 「清除记忆」功能实施计划（版本 0.8.0）

## 功能定义
- **记忆 = AI 答题缓存**（`chrome.storage.local` 中 `c:<24位hash>` 键，值 `{answer, note}`）
- 用途：AI 对某题一直答错时（错误答案被缓存反复复用），清除后下次开始会重新问 AI
- 弹窗介绍中明确说明三点：①不会清除/改动页面上已填写的答案 ②清除后下一轮所有题目重新问 AI、重新消耗额度 ③不影响已保存的 API Key 和接口配置

## 交互设计
1. **面板标题栏新增 🧹 按钮**（插在 ⚙ 与 — 之间，复用 `.iconbtn` 样式，title 提示"清除记忆"）
2. **首次点击 → 介绍确认弹窗**（config.clearAck 未设置时）：
   - 标题：「清除记忆（AI 答题记录）」
   - 正文：功能介绍 + 上述三点说明
   - 控件：「取消」／「立即清除」两个按钮 + **"以后不再提示"复选框**
   - 勾选后清除 → SET_CONFIG 写入 `clearAck: true`
3. **以后点击 🧹**（clearAck 已设）：直接清除，日志显示「已清除 N 条答题记忆，下次开始所有题目将重新问 AI」
4. **设置页加恢复入口**：「重新显示清除记忆的介绍提示」按钮（写回 clearAck: false），保证可逆

## 代码改动
### 1. background/service-worker.js（TEST_API 分支后插入）
```js
else if (type === 'CACHE_CLEAR') {
  const all = await chrome.storage.local.get(null);
  const keys = Object.keys(all).filter((k) => k.startsWith('c:'));
  if (keys.length) await chrome.storage.local.remove(keys);
  sendResponse({ ok: true, count: keys.length });
}
```
只删 `c:*`；保留 `config`（含 keyWarned/subjMode/clearAck）、`savedKeys`（Key 列表）、`apiEndpoint`（接口组合记忆）、`hwPanelPos/hwFabPos`（面板位置）。

### 2. content/homework/panel.js
- HTML：header 加 `<button class="iconbtn memclr" title="清除记忆：删除 AI 历史答案，答错反复出现时使用">🧹</button>`；新增 `.modal.memmodal` 块（复刻 .subjmodal 结构：标题 + 介绍正文 + `<label><input type="checkbox" class="memnever"> 以后不再提示</label>` + .mbtns 内 memcancel/memgo）
- els 注册：memclr / memmodal / memnever / memcancel / memgo
- 仿 `askSubjMode` 写 `askClearMemory()` Promise（返回 'go'|'never'|null；'never'=勾选后清除）；打开前先用 `CACHE_STATS`（或让 CACHE_CLEAR 带 dry-run 参数）把「当前共 N 条记忆」填进正文
- 事件：`els.memclr.click` → 读 config：clearAck 已设 → 直接 send CACHE_CLEAR + 日志；否则 → 弹窗；'go'/'never' → 清除（never 附带 SET_CONFIG {clearAck:true}）
- 日志带清除条数；清除后若面板有已渲染题目列表，行状态不变（本会话不追溯）

### 3. options/options.html + options.js
- 基本区加一行：按钮「重新显示「清除记忆」介绍提示」（仅当 clearAck 已设置时可见/可点）→ SET_CONFIG {clearAck:false}

### 4. manifest.json → version 0.8.0

## 测试计划（浏览器 stub e2e + Node 单测）
1. 预置 3 个 `c:` 假缓存 + config 无 clearAck：点 🧹 → 弹窗出现且正文含条数 → 勾选不再提示 + 立即清除 → 缓存清空、`savedKeys/apiEndpoint/config` 完好、clearAck=true、日志含条数
2. 再次点 🧹：无弹窗直接清除+日志
3. 弹窗中点取消：什么都不删
4. 设置页恢复按钮：clearAck 回 false → 再点 🧹 恢复弹窗
5. 回归：完整答题流程（检测→开始→缓存命中→清除记忆→再开始全部重新问）
6. 文档（README 界面/说明节）+ 记忆文件更新

## 说明
- 清除动作**只影响缓存**，不触碰：页面已填答案、API Key 列表、接口匹配结果、面板位置/展开状态
- 勾选"以后不再提示"后行为变为一键直接清除，无需二次确认（用户主动选择的结果，弹窗介绍已提前告知风险）
