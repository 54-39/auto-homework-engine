记忆

插件会把每道题的 AI 答案记在本机（答题记忆），同一题再次作答时直接使用；某道题一直答错时，清除后重新作答。

清除只删答题记忆，不改动页面上已填写的答案，也不影响 API Key 与接口配置。

    页面结构

    把最近打开的作业页面结构导出为 HTML 文件；站点适配失败时，把这个文件发给开发者即可排查。

    导出读取的是你最近访问过的那个网页，所以请先打开作业页面，再回到这里导出。

    检测更新

    打开本分区会自动检查一次（1 小时内不重复联网）。检查出新版后，点「更新」即可下载、校验并替换；失败会自动重试一次，再失败恢复旧版（作业页面需 F5）。

    点「更新」提示“更新组件尚未连接”时，说明这台电脑还没装更新组件：点「运行」看安装步骤，按提示运行插件目录里的 install-updater.cmd，只做一次。
