记忆

插件会把每道题的 AI 答案记在本机（答题记忆），同一题再次作答时直接使用；某道题一直答错时，清除后重新作答。

清除只删答题记忆，不改动页面上已填写的答案，也不影响 API Key 与接口配置。

诊断

把最近打开的作业页面结构导出为 HTML 文件；站点适配失败时，把这个文件发给开发者即可排查。

导出读取的是已打开的网页，所以请先打开作业页面，再回到这里导出。

检测更新

打开本分区会自动检查一次（1 小时内不重复联网）；发现新版后需手动下载并重新加载扩展（解压版无法自动更新）。更新不会强制：不自动安装、不影响使用，可继续用当前版本。
