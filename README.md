# 作业助手

适用于 Chrome / Edge 的超星学习通助手，支持 AI 辅助答题、课程学习队列和豆包网页桥接。

[下载最新版](https://github.com/54-39/auto-homework-engine/releases/latest) · [更新说明](https://github.com/54-39/auto-homework-engine/releases) · [问题反馈](https://github.com/54-39/auto-homework-engine/issues)

## 主要功能

| 模式 | 用途 | 使用方式 |
| --- | --- | --- |
| 解题（API） | 识别题目、生成参考答案、辅助填写 | 使用自己的 API Key，核对后手动提交 |
| 刷课（API） | 多门课程排队，逐章处理视频、文档、测验、讨论与问卷 | 使用自己的 API Key，自动处理任务和测验提交 |
| 豆包 | 通过豆包网页会话获取参考答案并填写 | 登录豆包网页版，无需 API Key |

- **识题与补漏**：支持单选、多选、判断、填空和简答；可调用 AI 补充识别页面题目。
- **课程接续**：跳过已完成章节，保留课程队列与本次范围，显示学习进度和预计用时。
- **豆包并排查看**：支持原生分屏的浏览器可同时查看作业与豆包，方便登录和处理验证。
- **本地记忆与诊断**：复用答题缓存，遇到问题可导出异常记录和页面现场。

## 安装

1. 在 [下载页面](https://github.com/54-39/auto-homework-engine/releases/latest) 选择 `homework-helper-版本号.zip`，解压到固定文件夹。
2. 打开 `chrome://extensions` 或 `edge://extensions`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的插件文件夹。
4. 打开超星页面，允许插件访问当前网站，点击页面上的悬浮按钮展开面板。

安装或更新后，已打开的课程、作业页面请按 **F5** 刷新一次。

## 开始使用

### 解题（API）

在面板选择「解题（API）」，粘贴 API Key 并保存。接口和模型可自动匹配，也可在「设置 → 应用设置」手动配置 OpenAI 兼容或 Anthropic 接口。

读取题目后开始填写；识别不全时点击「检测题目」调用 AI 补漏。**此模式只辅助填写，核对后由你提交。**API 用量按所选服务计费。

### 刷课（API）

在超星课程列表选择「刷课（API）」，勾选课程、设置倍速和静音，再点击「开始刷课」。也可以进入单门课程后开始。

插件会逐章处理任务，并使用 API 完成测验的答题和原生提交流程。点击「停止刷课」可暂停；处理好暂停原因后，点击开始接续原队列。**课程是否完成，以平台任务点的真实回执为准。**

### 豆包网页桥接

选择「豆包」并登录自己的豆包网页版。插件优先复用已有标签页，没有时再打开；点击「并排查看豆包」可在支持的浏览器中分屏查看。

遇到登录或验证提示时，先在豆包页处理，再回插件继续。刷课 API 与豆包桥接是两条独立流程。

## 更新与问题排查

- **更新插件**：GitHub 版在「设置 → 检测更新」检查新版。使用一键更新前，按页面指引运行插件目录里的 `install-updater.cmd`；也可下载新包，替换文件后在扩展管理页重新加载。更新后刷新课程页面。
- **课程列表为空**：先确认浏览器允许插件访问超星，再点击面板上的「刷新课程」。
- **卡住或漏任务**：在「设置 → 诊断」导出异常记录，反馈时附上插件版本和出问题的课程、节点。
- **需要验证码、人脸或重新登录**：由你完成验证后再继续，插件不会绕过这些验证。

AI 参考答案可能有误，请自行核对。配置和答题记忆保存在本机；题目会发送到你选择的 API 服务或豆包会话。详情见 [隐私政策](PRIVACY.md) 和 [使用许可](LICENSE)。
