# 作业助手｜Chrome / Edge 辅助写作业 AI 扩展

面向 Chrome 与 Edge 的辅助写作业工具：帮助提取题目、生成参考答案并辅助填写表单，供用户核对后提交。支持多家 API 与豆包网页桥接。

两种引擎可随时切换（面板上一键切换）：

| 引擎 | 费用 | 速度 | 状态 |
|---|---|---|---|
| API 引擎 | 按量（多家有免费额度） | 1~3 秒/题 | 可用（OpenAI 兼容：豆包方舟/DeepSeek/GLM/Kimi/通义/自定义） |
| 豆包网页桥接 | 免费（网页聊天额度） | 10~40 秒/题 | 可用（自动打开豆包标签页） |

## 豆包网页桥接（免费）

开始使用豆包网页桥接后，扩展会在后台打开或复用豆包标签页，将当前题目发送到你的豆包会话并读取回复。首次使用如遇登录或验证，请在豆包页面手动处理。每题之间会按设置的间隔等待；如遇验证或页面异常，队列会暂停并提醒你。

**验证提醒**：检测到消息未发出、登录或页面异常时，队列会暂停并发送**系统通知**（点击通知可直接跳转豆包标签页），面板同时显示提示。答题全部完成时也会系统通知提醒回来检查。

**后台运行（不用一直盯着）**：切到别的网页不影响答题。豆包回答监听用 MutationObserver 事件驱动（不受后台标签页定时器节流影响）；每题填写后有回读校验，没写进去自动重试重填；后台标签页写入失败会自动激活豆包标签页自愈重试一次。暂停/完成都有系统通知。

**题型支持**：单选/多选/判断/填空/简答（超星的「写作题」按简答处理：纯文本无 Markdown、标题行首空格近似居中、正文分段）。简答题同时支持普通 textarea 和 iframe 富文本编辑器（超星 UEditor 类）；超星的**判断题**（选项字母圈 `data` 上的 true/false）与**填空题**（每个空是一个 UEditor，交卷读编辑器正文而非隐藏 textarea）均已适配；超星隐藏 input、纯 li 选项列表均已兼容。遇到问题到设置页「诊断」导出页面结构用于精确适配。

## 页面原生识题与手动 AI 检测

打开学习通作业／测验页面后，插件先在本机直接读取原有题目并显示列表，不需要先点检测，也不需要配置 Key。常见单选、多选、判断、填空、简答继续沿用原生识别；章节中的同源 iframe 延迟加载或换题后会刷新列表。点击「开始」获取参考答案时仍需配置所选引擎。

页面原生识别不全时，用户可手动点击「检测题目」，把当前超星作业区域的可见文字与必要控件结构发送给面板所选 AI（API 或豆包桥接），由 AI 识别题干、题型、选项和填写位置；不需要截图，固定题型名称只作提示。只有手动检测才调用 AI 识题；检测和获取参考答案分别使用所选服务额度。长页面会分批分析，模型上下文不足、文字过长或不可读取的区域会提示处理限制。

识别后请先查看列表，再点击「开始」获取参考答案并辅助填写。支持单选、多选、判断、多空、文字作答和单选下拉框；普通文本框、contenteditable、同源富文本编辑器与下拉框混排时按页面顺序填写。材料题可拆为子题并关联共享材料原文，材料变化会使旧结果失效。填空逐空核对实际内容，少答、多答、错位或下拉值不能唯一匹配时停止。图片、跨域编辑区、上传、拖拽、连线／排序、多选下拉等无法可靠读取或填写的题显示「待确认」，刷课测验存在待确认题时不会交卷。字体混淆文字尚未解码，不保证此类题目能正确作答。

AI 只能返回本次页面已有的元素编号，插件会检查编号、控件类型、题目归属和重复引用，不执行模型生成的脚本或选择器。检测时不会发送密码、表单已有值、Cookie 或本机配置。详见 [隐私政策](PRIVACY.md)。网页文字中的恶意指令按资料处理；识别和参考答案仍需用户核对。

当前版本 **0.9.3**（修复选项文字包含关系导致的答案匹配冲突；包含原生识题误报修复、公式数据读取、手动 AI 检测、独立写题／刷课模式、全部静音、异常记录、课程预计用时与完成课程折叠）。

参考答案先匹配选项的完整文字，例如“同步通信”精确对应这一项，不会再因同时包含于“半同步通信”而误报失败。没有完整匹配时保留原有唯一匹配逻辑；空答案、重复同名选项和无法唯一确定的答案仍停止，不猜选项。

同一道题的嵌套容器不会重复计为待确认；隐藏选项模板、隐藏图片和附件不参与当前题目的校验。超星 `ans-latex-moudle` 公式图可直接读取节点自带的 LaTeX，保留题干及选项中的公式，不额外调用 AI。确实无法读取的图片仍提示确认，并保留已经识别出的题型。

验证命令：`node tools/test-ai-detection.mjs`（识别协议与引擎桩测试）、`node tools/test-ai-detection-browser.mjs`（真实无头浏览器中的页面采集／绑定／填写和面板状态）、`node tools/test-course-watch-browser.mjs`（刷课：嵌套同源 iframe 找视频、点站点倍速菜单、菜单没有的档位直写并守住、暂停时也定好倍速、停止后按住暂停）、`node tools/test-course-loop-browser.mjs`（整课遍历：目录逐节前进、三页签轮转、视频播完、测验交给面板、走完自动停、已做完的节点跳过）、`node tools/test-course-queue-browser.mjs`（课程列表识别与排队：勾选清单、已结束/已退课排除、页面类型判定、目录页点进第一门没做完的课、跳页后自动接力），默认查找本机 Edge，可通过 `EDGE_BIN` 指定 Chromium。自动化测试使用隔离页面与固定模型返回值，不使用个人账号或真实 AI 服务，不代表 AI 答案准确率。

本轮验证：21 组协议／引擎／后台及 JSON 合同检查通过，新增完整选项匹配优先、单选／多选包含关系、重复同名与歧义拒绝，以及 OpenAI／Anthropic 通道的回归。此前 33 组浏览器 DOM／界面、15 组课程队列测试通过；本次另用诊断页面结构和实际原始答案离线回放，确认精确映射 B、点击及回读一致，不访问个人账号或调用真实 AI。异常历史模拟累计 1502 条后全部保留并完整导出，覆盖旧记录迁移、分页及写入失败。界面覆盖桌面和 420×800 渲染。尚未完成跨多个课程连续长时间运行的实测；任务点完成也不代表测验满分。

## 刷课页面与预计用时

引擎选「API」，其下「模式」可切换「写题／刷课」；写题保留原答题界面。刷课页包含课程勾选、倍速、全部静音、状态和开始／停止。在当前课程启动会原地继续；列表页可勾选多门排队。静音立即作用于本页和同源嵌套视频，之后加载的视频也遵循该选项。

课程清单在名称后显示已知的预计剩余用时，无法读取进度时暂不显示。已完成课程放进默认收起的「已完成」区域，不参与「全选未完成」。进度延迟加载和用时更新不会丢掉勾选。进入课程后会在本机保留已读取的剩余任务数，返回清单可用于估算；开始刷课后，标题下持续显示剩余时间。估算基于剩余任务点与所选倍速；初始按 2 倍速约 4 分钟／任务点，之后按该课程实际耗时修正，不是全部视频时长的精确合计。

共用选项题按实际答题组顺序整理为多个选择空，每空保留完整选项文字，可处理超过八个备选项。填写后逐空回读，重复填写不会取消正确选中；选项文字内部的分号保留在同一个空内。未读取的图片、上传、拖拽等无法可靠处理的内容会保留为待确认，阻止自动提交。

## 异常记录

面板日志右侧点「异常记录」，或设置页 →「诊断」。只在识题、填写、刷课出错或测验丢分时记录；每次异常独立保存，不设自动淘汰条数，分页展示，导出包含全部历史。刷新、重载后仍保留，清除答题记忆不影响异常。旧记录保留备份并迁移。若写入失败，显示持续提醒并停止自动操作。记录只在本机，分享前可自行查看导出文件中的题目和答案。

修复了空答案 JSON 被误解析成 A、无法匹配选项仍回退 A、最后一个富文本填空未失焦保存的问题。旧答案缓存已隔离；这些修复不会自动恢复已经提交的成绩。

## API Key 配置

引擎切到「API」后，在出现的输入框粘贴 Key 点「保存」——**首次保存会弹窗三选**：`保存并记住`（进入面板下方的 Key 列表）/ `仅本次使用`（不进列表）/ `取消`。列表每条显示**尾号、供应商、记录时间**，可一键「使用」切换或「×」删除；删除正在使用的会自动停用。「停用」按钮只停用当前 Key 不删列表记录。

### 接口类型（自动识别）

**面板不再让你手选接口类型**（原来那个下拉换成了二次判断开关）：保存 Key 后并行尝试已知接口，谁先通过鉴权用谁；结果按 Key 尾号记住，之后秒连。需要手动指定协议时，到设置页的「接口类型」下拉里选：

| 选项 | 说明 |
|---|---|
| 自动识别（推荐） | 粘贴 Key 保存后并行尝试已知接口，谁先通过鉴权用谁；结果按 Key 尾号记住，之后秒连 |
| OpenAI 兼容 | 走 `{地址}/chat/completions`，适用 DeepSeek / 智谱 / Kimi / 火山方舟 / 通义 等 |
| Anthropic | 走 `{地址}/v1/messages`（Claude 系协议），如火山 Coding Plan、Z.ai |

### 二次判断开关

**选择题 / 判断题二次判断**（默认开）：多选与判断题先答一遍，再让 AI 复查一遍——复核提示词更严（先写理由、点名独立性/条件概率/互斥陷阱），复核不通过时不降级。关掉每题省一次 AI 调用。两处入口共用同一开关：**面板 API 抽屉里的开关**、设置页的勾选框。开关只影响 API 引擎，豆包桥接不做复核；答案缓存命中的题不再问引擎，也就不走复核。

**自动识别内置的服务**：DeepSeek、火山方舟、火山 Coding Plan、智谱 GLM、Kimi、Z.ai。按 Key 外观自动缩小尝试范围（UUID 格式走火山、带点格式走智谱）；`sk-` 开头的 Key 各平台长得一样，无法从外观区分，会自动逐个尝试。

### API 引擎稳定性

- **火山接口/模型自动匹配**：地址×模型组合并行探测（一轮完成，不串行等待），成功的组合记住后秒连；组合失效自动重新匹配
- 单次请求超时 120 秒；**任何一题失败立即暂停**整个队列（不做多次重试），原因写入日志
- 完成报告显示「填写 X 题 / 失败 Y 题」，失败的题目行点击可单题重答
- 修复后点「开始」整页重跑：已成功的题命中答案缓存，秒填不耗额度

### 豆包 API 免费路径

火山引擎控制台（console.volcengine.com/ark）→ 开通方舟 → 领取免费额度模型（如 doubao-lite 系列）→ 创建 API Key。把 Key 粘贴到面板保存即可，自动识别会匹配到火山地址。

## 更新检查

以下更新检查说明适用于 **GitHub 手动安装版**；Edge 商店版由商店更新，不显示此分区。

自动检查在 **设置页**：打开「检测更新」分区时自动对比 **GitHub 仓库** 上的最新版本（先读 GitHub API 拿实时版本号，失败回退 jsDelivr CDN 镜像，再回退官方 raw——大陆网络下 raw.githubusercontent.com 常被 DNS 劫持、jsDelivr 对 @master 最多缓存 12 小时；结果缓存 1 小时，失败静默不打扰）。

**更新永不强制**：不自动安装、不阻断使用，你可以一直用当前版本；需要时点「立即检查」绕过缓存，或从设置页/面板提示行的 GitHub 入口下载最新代码，再按「每次更新代码后」的步骤手动重载即可（插件自身在沙箱里不能替换文件；一键替换由本机脚本完成——见下文「自动更新（GitHub 版）」）。

面板只在**功能更新**（版本号第二段变化，如 0.4.x → 0.5.0）时显示提示行提醒；只有末位补丁号变化的修复更新不打扰面板，只在设置页安静显示。

## 自动更新（GitHub 版）

浏览器沙箱里的插件不能改写自身文件，自动替换由**本机脚本**完成，且**只在用户点了「更新」之后才执行**——不点不装、不常驻、不自动定时：

1. 首次使用：打开设置页「检测更新」，点「运行」→ 页面会列出**在哪、双击哪个文件**：在文件资源管理器里打开插件目录，双击里面的 `install-updater.cmd`。它会读取 Edge profile，自动查找当前加载的作业助手目录，无法唯一确认时才弹出文件夹选择框。安装器按需下载并校验 Node.js v24.21.0，只放在插件目录的 `.native-runtime/`，不改系统 PATH；**若插件目录里已有 `node-v24.21.0-win-x64.zip`（完整离线包自带），就地解压、全程不联网**。设置页会在返回或重新显示时重新 ping；扩展 ID 和版本都匹配后，「运行」按钮才隐藏。
2. 日常更新：设置页发现新版后点「更新」。更新器先锁定一个提交，清单、manifest 和全部文件都从该提交读取；先下载到 `.update-stage/`、验证 SHA-256/文件树摘要、manifest 版本、脚本语法和声明资源完整性，再备份旧文件并替换，manifest 最后写入。下载时进度条按已下载并校验的文件数更新；文件下载速度取决于网络。Windows 上独立更新进程会沿用已有 HTTP(S)_PROXY；未设置代理变量时读取系统代理，并使用系统证书库。网络失败会显示请求主机和底层错误，便于判断连接或证书问题。工具脚本本身也在载荷内，因此更新器可以随版本升级。
3. 更新由独立 Node 进程跨浏览器重载继续运行。新后台和设置页初始化后会用事务 ID、目标版本、提交和扩展 ID发送健康回执；确认成功后才删除备份与淘汰文件。下载、写入或健康验证失败会在同一提交上完整重拉一次，再失败恢复旧文件，并提示需要时到扩展管理页手动重载。设置页会显示下载、替换、验证、重试、成功或回滚状态；成功后作业页面仍需 F5。

更新范围包含浏览器实际加载的文件、修复 CMD 和 `tools/` 下的更新器脚本。安装器生成的 `tools/native-host.exe`、`.native-runtime/`、测试脚本和 README 等本地文件不会被覆盖。更新器不提供绕过事务的手动直接写入入口；固定提交无法读取时会停止，不拼接分支缓存文件。

**完整离线包**（给没网/网络差的电脑）：执行 `node tools/make-offline-bundle.mjs`，会在 `dist/` 生成一个 zip，里面是可直接加载的插件目录 + 一份 `node-v24.21.0-win-x64.zip`。对方解开、加载目录，点「运行」后双击 `install-updater.cmd`，安装器就地解压这份 Node，**全程不联网**。加 `--no-node` 可打不含 Node 的小包（装的时候要联网）。

## 刷课（整门课自动走一遍）

面板「检测题目」那一行下面多了一行：倍速下拉 + 「全部静音」选项 + 「刷课」按钮。

**在课程列表页**（`mooc2-ans.chaoxing.com/visit/interaction`，也就是「我学的课」那页）打开面板，会列出你所有的课，每门带「已完成/总数」和勾选框：

- 勾一门或几门（顶上是「全选（N 门）」），按钮会跟着变成「刷 N 门」
- 点它，插件从第一门开始：先进这门课的目录页，只点**没做完**的节点，一节节刷完，再自动翻下一门
- 已结束、已退课的课不会出现在清单里
- 一门课全部做完就跳过它，日志会说「这门课走完了（跳过已完成 N 节）」
- 中途随时点「停止刷课」（排队没了，不会再往下翻）

**在某一节课的学习页**点「刷课」也可以，就只刷当前这门课。因为点目录是整页跳转，页面一换脚本就重来，所以这里也走后一条排队通道——跳页后按钮会自己变回「停止刷课」、日志接着写，不用你再点一次。

进入课程后，沿着右侧课程目录一节一节往下走，每节遍历站点实际提供的全部页签，等待对应卡片加载完成后按内容处理：

- **元典阅读 / 文档类**：打开停留；嵌有视频任务时继续播放视频。最终以目录任务点复查为准
- **视频讲义**：找到视频就开始播，倍速默认「自动（最高档）」——先看播放器自己的倍速菜单最高给到几倍（多数课 1.5x / 2x，个别课 4x），就按那档跑完；也能手动锁 1x / 1.25x / 1.5x / 2x
- **章节测验**：先读取原生题目，再使用所选引擎获取参考答案并填写；漏检时暂停，用户可手动点击「检测题目」调用 AI。完整填写并校验后点击站点提交按钮及确认框；请先确认课程平台和学校规则允许自动提交
- **本章讨论**：优先回复当前章节已有讨论；没有可回复的帖子时自动新建一条，避免重复发帖
- 走完最后一节自动停下，日志提示「整门课已走完一遍」；中途随时点「停止刷课」
- 按目录任务点估算总量，并以已完成章节的实测耗时估算、显示剩余时间；估算会随实际进度更新

关键行为：

- **优先模拟点击**：开始播放点播放器自己的播放按钮，切倍速点播放器「播放速度」菜单里对应那一项，切页签点站点自己的页签、切章节点目录里的章节名——和手点等价，不改站点脚本
- **站点菜单里没有的档位才直写**：选的档位超过播放器菜单上限时，插件直接写 `<video>` 的 `playbackRate`，并且每 0.5 秒守一次——播放器换源/重载把倍速重置回 1 也会被改回去（暂停状态下也先把倍速定好，点开播就是目标速度）
- **能拖进度条的课就拖**：每节先试一次把进度拖到最后，拖得动就直接交卷走人；拖不动（多数课会锁进度条，按观看时长校验）就老老实实按倍速播完
- **停止会真的把视频按暂停**：点「停止刷课」后除了停下脚本，还会点播放器自己的暂停按钮，并在之后 5 秒内继续按住，防止站点自己把播放接回去
- 播放器连续 5 次点不起播放就提示你手点一下播放，不跟站点反复拉扯
- 只处理原生 `<video>`；PPT、文档、阅读类没有可靠完成信号，只做页签停留
- 倍速选择记在本机配置里，下次打开还是这个档位
- **全部静音**：默认勾选，当前课程标签页里的全部视频（含跨域播放器和后续加载的视频）都会静音；取消勾选恢复声音。选择会保存，刷新或切换章节后继续沿用。
- 同页多个视频会跳过站点已标完成的视频，只操作当前待完成视频所属播放器的控件；第一个播完后继续下一个
- 单课与多课队列都会复查剩余任务点并补刷一轮；仍未完成时保留队列、明确列出未完成章节，不报课程完成
- AI 识题、填写失败或超时时停止当前流程，不自动提交这份测验

自动提交测验和自动发讨论帖已通过 fixture 测试，但尚未在真实课程中完整验证；首次使用前请留意页面操作结果。

## 设置页

面板标题栏点「设置」打开独立设置页（独立标签页，左侧边栏切换：记忆 / 诊断 / 检测更新；当前分区记在地址栏，刷新与前进后退都停在原分区；窄窗口自动折叠成顶部导航）：

- **记忆**：顶部显示当前已记住的答题记忆条数，下面是清除 AI 答题记忆（缓存）。首次清除有确认，可勾选「以后不再提示」直接清除
- **诊断**：把你最近访问过的那个网页结构导出为 HTML 文件（先在作业页停留，再回到这里导出；站点适配失败时发给开发者排查）
- **检测更新**：显示当前版本与最新版本；打开本分区自动检查一次，「立即检查」绕过 1 小时缓存；首次使用点「运行」，页面会告诉你插件目录在哪、双击里面的 `install-updater.cmd`（不再经过浏览器下载）。安装器自动寻找 Edge 当前加载的目录并安装私有 Node 环境；无法确认目录时才要求手选。回到设置页后会重新验证宿主，只有扩展 ID 和版本都匹配才隐藏按钮；发现新版后点「更新」才自动下载替换。检查失败可直接重试，更新不强制

## 界面

- 视觉按 Pixso 设计稿实现
- **API 配置收纳为可折叠抽屉**：API 引擎下「接口 与 API Key」块可点标题折叠/展开；折叠状态记忆在本机；豆包桥接下整块消失。非 API 模式与折叠模式面板同尺寸（72vh），展开抽屉时面板整体适当变高（至多近全屏），多出的空间留给题目列表和日志，背景光晕固定半径不随高度拉伸：**无图标、纯文字**风格——浅色渐变卡片面板、蓝底白字 ⚡ 悬浮球、标题栏文字按钮（展开/设置/收起）、题目行尾文字状态（待机/获取中/填入/改对/保留/失败）
- **面板和悬浮球都可拖动**：面板按住标题栏拖到任意位置（别挡住题目/提交按钮）；⚡ 悬浮球也能拖（拖动和点击自动区分，拖了就不会误开面板）
- **提示气泡在面板内自绘**：按钮/列表行的说明文字是自绘圆角气泡（鼠标悬停与键盘聚焦都会出现，跟随目标并在屏幕内收边），不再用浏览器原生的 `title` 系统气泡
- **浏览器原生控件表面已统一主题**：选中文字、输入光标、键盘焦点环、滚动条、复选框都按面板的蓝色主题着色，Windows 深色模式下也不出现原生的黑边/黄底控件
- **「引擎」（面板）与「接口类型」（设置页）是自绘下拉**（`content/homework/dropdown.js`，面板与设置页共用）：原生 select 的展开层是系统窗口、样式改不到，所以弹层由插件自己画——每项一行只放名称（整段说明放控件下方，不塞进列表），选中的那项是淡蓝底 + 加粗、鼠标悬停是中性灰底（两者一眼分得开）；支持 ↑↓ 移动、Enter/Space 选中、Esc 关闭、点击控件外关闭，焦点始终留在控件上。面板里原「接口类型」的位置换成了**选择题 / 判断题二次判断开关**（自绘开关：关态浅灰、开态淡浅蓝、和面板背景同色；小球里是播放三角，切换时滑过去并原地转一圈）。
- **API Key 输入框的标签不带底色**：输入框有内容或获得焦点时，标签浮到输入框上方（原先压在边框上且垫了一块白底，会盖住边框）
- 位置**按网站记住**（刷新、下次打开还在原地），双击面板标题栏一键复位到右下角默认位置
- **清除记忆**：删除 AI 历史答题缓存（同一题反复答错、错误答案被缓存复用时用）。入口在设置页「记忆」（点面板标题栏「设置」打开）；首次清除弹确认，可勾选「以后不再提示」直接清除；清除只删答案缓存，不动页面已填答案、API Key、接口配置；下一轮所有题目重新问 AI（重新耗额度）
- 拖动时自动限制在屏幕范围内，不会拖丢

## 提交与重跑

- **插件只填写、永不自动提交**——检查无误后请自行点提交（此设计无开关，防止误交）
- **逐题核对**：每道题先读页面状态 → 没写直接写；写了就与参考答案（缓存）比对，写对跳过、写错自动改写；页面状态读不出来时视为没写直接写（重填有防取消保护）。比对不消耗引擎调用
- 注意：超星会把已填答案从服务器恢复到页面（重新打开作业页时选项可能自动带出旧答案），插件会照常核对填写，不影响结果

### 火山 Key 免配置细节

- 保存火山 Key（UUID 格式）后自动探测：同时尝试 Coding 套餐地址（`/api/coding`）与按量地址（`/api/v3`）
- **模型名自动匹配**：预填模型不存在（404）时，引擎自动遍历候选模型（doubao-seed-code / doubao-seed-2-0-code / kimi-k2-thinking / deepseek-v3-2 / glm-4-7），成功的自动记住（按 Key 尾号绑定，之后秒连）
- 组合失效（401/403/404）自动重新匹配一次
- 也可以手动指定：到设置页把接口类型选「OpenAI 兼容」或「Anthropic」，地址和模型照抄套餐「使用配置」页
- **Key 自动清理**：保存 Key 时自动去除混入的中文/全角符号/空格（这类字符会让请求根本发不出去），并提示清理后的尾号供核对；鉴权失败(401)的报错会显示当前接口地址，方便发现"Key 与接口不匹配"
