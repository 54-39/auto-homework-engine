# 作业助手

适用于 Chrome / Edge 的超星学习通助手，支持 AI 辅助答题、课程学习队列和豆包网页桥接。

[下载最新版](https://github.com/54-39/auto-homework-engine/releases/latest) · [更新说明](https://github.com/54-39/auto-homework-engine/releases) · [问题反馈](https://github.com/54-39/auto-homework-engine/issues)

## 主要功能

| 模式 | 用途 | 使用方式 |
| --- | --- | --- |
| 解题（API） | 识别题目、生成参考答案、辅助填写 | 使用自己的 API Key，核对后手动提交 |
| 刷课（API） | 多门课程排队，逐章处理视频、文档、测验、讨论与问卷 | 使用自己的 API Key，自动处理任务和测验提交 |
| 豆包 | 通过豆包网页会话获取参考答案并填写 | 登录豆包网页版，无需 API Key |

- **识题与补漏**：支持单选、多选、判断、填空和简答；题干、选项和共享材料中的图片会随题目一并交给 AI；可调用 AI 补充识别页面题目。
- **课程接续**：跳过已完成章节，保留课程队列与本次范围，显示学习进度和预计用时。
- **豆包查看方式**：点击开始自动分屏，可在设置中改用新窗口，方便登录和处理验证。
- **本地记忆与诊断**：复用答题缓存，遇到问题可导出异常记录和页面现场。

## 安装

Edge 用户也可从 [Edge 扩展商店](https://microsoftedge.microsoft.com/addons/detail/cblgpldccbkadljnllpjlodafooehngg) 安装，商店版由浏览器管理更新。

1. 在 [下载页面](https://github.com/54-39/auto-homework-engine/releases/latest) 选择 `homework-helper-版本号.zip`，解压到固定文件夹。
2. 打开 `chrome://extensions` 或 `edge://extensions`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的插件文件夹。
4. 打开超星页面，允许插件访问当前网站，点击页面上的悬浮按钮展开面板。

安装或更新后，已打开的课程、作业页面请按 **F5** 刷新一次。

## 开始使用

### 解题（API）

在面板选择「解题（API）」，粘贴 API Key 并保存。接口和模型可自动匹配，也可在「设置 → 应用设置」手动配置 OpenAI 兼容或 Anthropic 接口。

读取题目后开始填写；识别不全时点击「检测题目」调用 AI 补漏。**此模式只辅助填写，核对后由你提交。**API 用量按所选服务计费。

纯文字题按最多 5 题一批发送，API 引擎最多两批并行；单次作答直接采用，只有模型漏题或空答案时才补问缺的题。含图题会附带题图：优先直读超星原图，读不到时截取当前可见页面并按题裁剪，需先点击浏览器工具栏的扩展图标授权当前页面，并保持作业标签页在前台可见。

### 刷课（API）

在超星课程列表选择「刷课（API）」，勾选课程、设置倍速和静音，再点击「开始刷课」。也可以进入单门课程后开始。

插件会逐章处理任务，并使用 API 完成测验的答题和原生提交流程。点击「停止刷课」可暂停；处理好暂停原因后，点击开始接续原队列。**课程是否完成，以平台任务点的真实回执为准。**

### 豆包网页桥接

选择「豆包」后点击「开始」，插件自动分屏并优先复用已有豆包页面。可在「应用设置 → 豆包网页桥接 → 打开方式」选择分屏模式或新窗口模式；不支持自动分屏的浏览器使用新窗口。

连续题目沿用当前豆包对话，每次只读取本题的新回复。遇到登录或验证提示时，先在豆包页处理，再回插件继续。刷课 API 与豆包桥接是两条独立流程。

题目列表支持单击只答当前题，右键从当前题开始依次作答；键盘 Enter 答当前题，Shift+Enter 从当前题开始。正在答题时先停止，再选择新的起点。

## 更新与问题排查

- **v1.1.0 版本说明**：合并 1.0.8–1.0.25 的全部改动——批量答题与题图（最多 5 题一批、两批并行）、单次作答不再重复问同一题、DeepSeek 模型下拉（flash / chat / reasoner，reasoner 可在面板看思考过程）、填空数值先验算、答案缓存按模型区分、已提交查看页只读防护、设置页「重问时先确认」开关。
- **默认 flash 与查看页防护（v1.0.25）**：DeepSeek 自动匹配与手动下拉的默认模型改回 `deepseek-flash`，下拉下方写明 flash（最快最便宜、复杂题易错）、chat（均衡）、reasoner（最准最贵、显示思考过程）的差别与适用题型。已提交的作业查看页（`/work/view` 或出现「我的答案/正确答案」）不再列出「可处理 N 题」并禁用开始，避免把只读页面当成可作答页。
- **答案缓存按模型区分（v1.0.24）**：答题记忆的键加入模型名并把缓存版本升到 v4——换模型（chat / flash / reasoner / 豆包）后会重新问 AI，不再复用旧模型留下的答案；旧缓存记录随之失效，可在「设置 → 记忆」清除。
- **模型下拉与填空验算（v1.0.21–v1.0.23）**：设置页「手动配置接口」的模型名改为下拉选项，并按接口地址所属服务商给出：DeepSeek 地址列出 `deepseek-chat`、`deepseek-flash`、`deepseek-reasoner`（默认 chat），火山、智谱、Kimi、Z.ai 各自列自己的模型，换服务商不会再看到别家的模型；只有不在预设里的服务商才显示「自定义…」。v1.0.22 修正下拉加载后仍显示为禁用、点不开的问题；填空题与数值题要求模型先列算式并代回题设验算后再输出数值；页面答案与 AI 一致时提示「与 AI 参考答案一致」，不再写成「答案正确」。v1.0.23 选 `deepseek-reasoner` 时，面板日志会显示该题的思考过程；chat/flash 不返回思考内容，思考 token 按用量计费。
- **重问保护与默认模型（v1.0.20）**：设置页新增「单题重问时先确认」，新答案与页面已填不同时只提示，再点一次重问才覆盖，避免错误的 AI 答案覆盖正确结果；不需要时可在「设置 → 应用设置」关掉。DeepSeek 自动匹配默认模型改为 `deepseek-chat`，此前匹配到的 `deepseek-flash` 会在下次使用时自动迁移。
- **去掉二次复核（v1.0.19）**：同一道题不再问两遍（题目相同模型必然给相同答案，复核没有区分度），单次作答直接采用并标记「单次作答」；只在模型漏题或空答案时才补问缺的题。答题耗时约减半。
- **上下标可读化（v1.0.18）**：公式里的 `x_i`、`p_{11}`、`p_ij` 这类下标源码转成 Unicode（`xᵢ`、`p₁₁`、`pᵢⱼ`），上标同理，题干和选项不再出现下划线源码。
- **公式题不再截图（v1.0.17）**：题干和选项里的公式图自带 LaTeX 源码（`ans-latex-moudle` 的 `data` 属性），插件读出来转成可读符号后直接发文字，不再触发截图和上传；只有存在读不出文字的真实图片（照片、图表、手绘、材料图）时才整题截图一张。纯公式题不再需要点工具栏图标授权。
- **题目文字可读化（v1.0.16）**：发给 AI 的题干和选项不再出现重复字母前缀（`A. A …`）和 LaTeX 源码（`$P(X \leq 3)$`），公式统一转成可读符号（`P(X ≤ 3)`）；题块截图失败时直接提示「最大化作业窗口后重试」，不再退回多张碎片公式图。
- **豆包图片上传（v1.0.15）**：新版豆包不再把文件上传控件放在输入框附近，改为全文档查找 file input，找不到就把整题图作为粘贴数据交给编辑器；上传确认失败也不再暂停整轮（文字里已有完整公式）。
- **整题截图（v1.0.14）**：题目里只要有图片（含公式图），插件就截取**整个题块**（题干+全部选项+渲染后的公式）作为一张图发给 AI，不再逐张上传公式图；豆包发送后的图片确认改为以上传前预览为准，不再因气泡不渲染图片而整轮暂停。需要先点工具栏图标授权当前页面截图。
- **公式题附图（v1.0.13）**：题干和选项里的公式图片（超星 `ans-latex-moudle`）重新随题目上传给 AI，不再只发 LaTeX 文字；豆包回复里的公式片段改为按 DOM 顺序还原原文，JSON 里 `\leq` 这类非法转义也会被修复后再解析。API 引擎同样适用。更新后重载扩展并刷新作业页；原图读不到时仍需点击工具栏图标授权截图。
- **猜选治理（v1.0.12）**：模型批量漏题或个别空答时，插件只对缺的题自动补问一次，补不到才走猜选；选择、判断题提示词改为必须作答，多选题宁缺勿滥（错选 0 分、漏选有部分分）。更新后重载扩展并刷新作业页。
- **题图与批量答题（v1.0.11）**：题干、选项和共享材料中的图片随题目一起交给 AI（优先直读超星原图，失败时按题裁剪当前可见页面）；纯文字题按最多 5 题一批处理，最多两批并行，客观题独立复核。数值题会核对模型给出的关键等式，结果与选项冲突时留待核对。豆包桥接同样支持题图上传与批量提问。更新后重载扩展并刷新作业页；首次截图需点击工具栏图标授权。
- **分数选项（v1.0.10）**：支持将 AI 返回的简单分数与页面 LaTeX 分数匹配；手动解题时要求计算结果与选项不符的题目留待核对。
- **客观题核对（v1.0.9）**：单选复核会逐项检查选项是否符合题意，避免只重复初答推理；判断题核对关键术语、限定条件和整句真假。答案不一致或无法复核时暂停该题。可在设置中关闭二次判断以减少 API 调用。更新后重载扩展并刷新作业页。
- **章节测验多选题（v1.0.7）**：修复新版样式选项被误识别成单选、中文和英文逗号导致相同答案匹配失败的问题；重答时可准确取消旧错选，重复填写保留目标选项。更新后刷新作业页面，重新作答原先失败或标为「猜选」的题目。
- **面板比例（v1.0.5）**：普通面板恢复约 350 × 770 的修长外框；切换模式或折叠 API 区域保持尺寸，题目列表利用剩余空间，日志不再空撑。较小窗口按可用空间适配，低矮窗口在面板内滚动。
- **更新插件**：GitHub 版在「设置 → 检测更新」检查新版。使用一键更新前，按页面指引运行插件目录里的 `install-updater.cmd`；也可下载新包，替换文件后在扩展管理页重新加载。更新后刷新课程页面。
- **课程列表为空**：先确认浏览器允许插件访问超星，再点击面板上的「刷新课程」。
- **答错、卡住或漏任务**：先在「设置 → 诊断」勾选「记录诊断」（默认关闭），对出错题目重新作答以重现问题，再导出异常记录，将 JSON 文件发送至 477158632@qq.com。最好附上题干、选项、实际填写答案和平台正确答案的截图，并说明版本、课程和题号。发送前请遮挡个人信息、密码和 API Key；反馈由你主动发送。
- **需要验证码、人脸或重新登录**：由你完成验证后再继续，插件不会绕过这些验证。
- **熄屏与后台运行**：电脑需保持运行，睡眠或休眠时不能继续。后台暂停先恢复播放，失败后自动重载播放器一次；仍失败则记录未完成并继续，不自动切换到浏览器前台。

AI 参考答案可能有误，请自行核对。配置和答题记忆保存在本机；题目会发送到你选择的 API 服务或豆包会话。详情见 [隐私政策](PRIVACY.md) 和 [使用许可](LICENSE)。
