# 作业助手（Chrome / Edge 浏览器插件）

自动完成网页作业：提取题目 → AI 答题 → 自动填写。

两种引擎可随时切换（面板上一键切换）：

| 引擎 | 费用 | 速度 | 状态 |
|---|---|---|---|
| API 引擎 | 按量（多家有免费额度） | 1~3 秒/题 | 可用（OpenAI 兼容：豆包方舟/DeepSeek/GLM/Kimi/通义/自定义） |
| 豆包网页桥接 | 免费（网页聊天额度） | 10~40 秒/题 | 可用（自动打开豆包标签页，免登录可用） |

## 豆包网页桥接（免费）

答题时插件自动控制豆包标签页：**不需要先打开豆包**——开始答题时没有豆包标签页会自动新开；免登录可用（如遇豆包风控验证，去豆包标签页手动通过一次即可）。每题自动新开对话 → 输入问题 → 等回答生成完 → 取回答案，题目之间随机延迟 3~8 秒模拟人工节奏。

**风控提醒**：检测到消息发不出/页面异常（风控、登录墙）时，第一次就会立即暂停队列并发送**系统通知**（点击通知可直接跳转豆包标签页），面板同时显示红字警示——不会反复重试去撞验证码。答题全部完成时也会系统通知提醒回来检查。

**后台运行（不用一直盯着）**：切到别的网页不影响答题。豆包回答监听用 MutationObserver 事件驱动（不受后台标签页定时器节流影响）；每题填写后有回读校验，没写进去自动重试重填；后台标签页写入失败会自动激活豆包标签页自愈重试一次。暂停/完成都有系统通知。

**题型支持**：单选/多选/判断/填空/简答。简答题同时支持普通 textarea 和 iframe 富文本编辑器（超星 UEditor 类）；超星隐藏 input、纯 li 选项列表均已兼容。遇到问题点面板 🐞 导出页面结构用于精确适配。

## 安装（只做一次）

1. Chrome 打开 `chrome://extensions`（Edge 打开 `edge://extensions`）
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」→ 选择本项目根目录

## API Key 配置

引擎切到「API」后，在出现的输入框粘贴 Key 点「保存」——**首次保存会弹窗三选**：`保存并记住`（进入面板下方的 Key 列表）/ `仅本次使用`（不进列表）/ `取消`。列表每条显示**尾号、供应商、记录时间**，可一键「使用」切换或「×」删除；删除正在使用的会自动停用。「停用」按钮只停用当前 Key 不删列表记录。

### 供应商与 Key 的匹配（重要）

**面板直接可切**：引擎切到 API 后，面板上就有供应商下拉，每个选项都标注了"哪家的 Key 能用"：

| 下拉选项 | 能用的 Key |
|---|---|
| 火山Coding套餐 | 火山 Coding Plan（包月）控制台的 Key → 地址 `/api/coding` |
| 火山方舟按量 | 火山方舟按量 Key（免费额度模型）→ 地址 `/api/v3` |
| DeepSeek | platform.deepseek.com 的 Key |
| 智谱 GLM | bigmodel.cn 的 Key（含免费 glm-4-flash） |
| Kimi | platform.moonshot.cn 的 Key |
| 通义千问 | 阿里云百炼的 Key |
| Z.ai Coding（国际） | z.ai Coding Plan 的 Key |
| 自定义 | 任意 OpenAI 兼容接口 |

**保存 Key 时自动识别**：火山方舟 Key（UUID 格式）和智谱 Key（id.secret 带点格式）会自动给出归属判断，智谱的自动切换供应商；`sk-` 开头的 Key 各平台长得一样、无法自动区分，会提示你核对下拉选择。

### API 引擎稳定性

- **火山接口/模型自动匹配**：地址×模型组合并行探测（一轮完成，不串行等待），成功的组合记住后秒连；组合失效自动重新匹配
- 单次请求超时 25 秒；**任何一题失败立即暂停**整个队列（不做多次重试），原因写入日志
- 完成报告显示「填写 X 题 / 失败 Y 题」，失败的题目行点击可单题重答
- 修复后点「开始」整页重跑：已成功的题命中答案缓存，秒填不耗额度

### 豆包 API 免费路径

火山引擎控制台（console.volcengine.com/ark）→ 开通方舟 → 领取免费额度模型（如 doubao-lite 系列）→ 创建 API Key。设置页选「豆包 · 火山方舟」会自动填好地址。

## 每次更新代码后

- 手动：`chrome://extensions` 点插件卡片上的 ↻ 重新加载 + 刷新页面 F5
- 或热重载：`node tools/watch.mjs`（代码一变插件自动重载，页面仍需 F5）

## 界面

- 视觉按 Pixso 设计稿实现（v0.9.0）
- **API 配置收纳为可折叠抽屉**（v0.9.1）：API 引擎下「接口 与 API Key」块可点标题折叠/展开；折叠状态记忆在本机；豆包桥接下整块消失。非 API 模式与折叠模式面板同尺寸（72vh），展开抽屉时面板整体适当变高（至多近全屏），多出的空间留给题目列表和日志，背景光晕固定半径不随高度拉伸：**无图标、纯文字**风格——浅色渐变卡片面板、白底蓝字「答」字悬浮球、标题栏文字按钮（展开/诊断/记忆/收起）、题目行尾文字状态（待机/获取中/填入/改对/保留/冲突/失败）
- **面板和悬浮球都可拖动**：面板按住标题栏拖到任意位置（别挡住题目/提交按钮）；「答」字悬浮球也能拖（拖动和点击自动区分，拖了就不会误开面板）
- 位置**按网站记住**（刷新、下次打开还在原地），双击面板标题栏一键复位到右下角默认位置
- **🧹 清除记忆**：删除 AI 历史答题缓存（同一题反复答错、错误答案被缓存复用时用）。首次点击弹介绍窗（可勾选「以后不再提示」，设置页可恢复）；清除只删答案缓存，不动页面已填答案、API Key、接口配置；下一轮所有题目重新问 AI（重新耗额度）
- 拖动时自动限制在屏幕范围内，不会拖丢

## 提交与重跑

- **插件只填写、永不自动提交**——检查无误后请自行点提交（此设计无开关，防止误交）
- **逐题核对**：每道题先读页面状态 → 没写直接写；写了就与参考答案（缓存）比对，写对跳过、写错自动改写；页面状态读不出来时视为没写直接写（重填有防取消保护）。比对不消耗引擎调用
- 注意：超星会把已填答案从服务器恢复到页面（重新打开作业页时选项可能自动带出旧答案），插件会照常核对填写，不影响结果

### 火山 Coding Plan 免配置细节

- 保存火山 Key（UUID 格式）自动选择「火山Coding套餐」预设（地址 `/api/coding`）
- **模型名自动匹配**：预填模型不存在（404）时，引擎自动遍历套餐候选模型（doubao-seed-code / doubao-seed-2-0-code / kimi-k2-thinking / deepseek-v3-2 / glm-4-7），成功的自动记住（按 Key 尾号绑定，之后秒连）
- 按量/Coding 地址互为兜底：401 时自动换另一个地址重试
- 模型名也可以手动照抄套餐「使用配置」页的模型 ID
- **Key 自动清理**：保存 Key 时自动去除混入的中文/全角符号/空格（这类字符会让请求根本发不出去），并提示清理后的尾号供核对；鉴权失败(401)的报错会显示当前接口地址，方便发现"Key 与供应商不匹配"

## 目录结构

```
manifest.json              # MV3 配置
background/
  service-worker.js        # 队列、缓存、引擎路由、热重载
  engines/
    engine.js              # 共享：Prompt 构建 / 答案解析 / 哈希
    api-engine.js          # OpenAI 兼容 API 引擎
    bridge-engine.js       # 豆包桥接（M2）
content/
  homework/
    extractor.js           # 题目提取（通用启发式）
    filler.js              # 答案填写（React/Vue 兼容）
    panel.js               # 悬浮面板（Shadow DOM）
    content.js             # 入口
  doubao/doubao-bridge.js  # 豆包页桥接脚本（M2）
options/                   # 设置页
tools/watch.mjs            # 热重载监听
```

## 说明

- 桥接引擎需保持豆包标签页登录状态；已内置随机延迟缓解风控风险，建议仅自用
- 建议用于练习自测与答案核对场景，留意所在学校/平台的使用规则
