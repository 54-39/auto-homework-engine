# 作业助手（Chrome / Edge 浏览器插件）

自动完成网页作业：提取题目 → AI 答题 → 自动填写。

两种引擎可随时切换（面板上一键切换）：

| 引擎 | 费用 | 速度 | 状态 |
|---|---|---|---|
| API 引擎 | 按量（多家有免费额度） | 1~3 秒/题 | 可用（OpenAI 兼容：豆包方舟/DeepSeek/GLM/Kimi/通义/自定义） |
| 豆包网页桥接 | 免费（网页聊天额度） | 10~40 秒/题 | 可用（自动打开豆包标签页） |

## 豆包网页桥接（免费）

答题时插件自动控制豆包标签页：**不需要先打开豆包**——开始答题时没有豆包标签页会自动新开。首次使用如遇登录或风控验证，在豆包标签页手动通过一次即可。每题自动新开对话 → 输入问题 → 等回答生成完 → 取回答案，题目之间随机延迟 3~8 秒模拟人工节奏。

**风控提醒**：检测到消息发不出/页面异常（风控、登录墙）时，第一次就会立即暂停队列并发送**系统通知**（点击通知可直接跳转豆包标签页），面板同时显示红字警示——不会反复重试去撞验证码。答题全部完成时也会系统通知提醒回来检查。

**后台运行（不用一直盯着）**：切到别的网页不影响答题。豆包回答监听用 MutationObserver 事件驱动（不受后台标签页定时器节流影响）；每题填写后有回读校验，没写进去自动重试重填；后台标签页写入失败会自动激活豆包标签页自愈重试一次。暂停/完成都有系统通知。

**题型支持**：单选/多选/判断/填空/简答（超星的「写作题」按简答处理：纯文本无 Markdown、标题行首空格近似居中、正文分段）。简答题同时支持普通 textarea 和 iframe 富文本编辑器（超星 UEditor 类）；超星隐藏 input、纯 li 选项列表均已兼容。遇到问题到设置页「诊断」导出页面结构用于精确适配。

## 安装（只做一次）

1. Chrome 打开 `chrome://extensions`（Edge 打开 `edge://extensions`）
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」→ 选择本项目根目录

## API Key 配置

引擎切到「API」后，在出现的输入框粘贴 Key 点「保存」——**首次保存会弹窗三选**：`保存并记住`（进入面板下方的 Key 列表）/ `仅本次使用`（不进列表）/ `取消`。列表每条显示**尾号、供应商、记录时间**，可一键「使用」切换或「×」删除；删除正在使用的会自动停用。「停用」按钮只停用当前 Key 不删列表记录。

### 接口类型（面板 / 设置页可选）

| 选项 | 说明 |
|---|---|
| 自动识别（推荐） | 粘贴 Key 保存后并行尝试已知接口，谁先通过鉴权用谁；结果按 Key 尾号记住，之后秒连 |
| OpenAI 兼容 | 走 `{地址}/chat/completions`，适用 DeepSeek / 智谱 / Kimi / 火山方舟 / 通义 等 |
| Anthropic | 走 `{地址}/v1/messages`（Claude 系协议），如火山 Coding Plan、Z.ai |

**自动识别内置的服务**：DeepSeek、火山方舟、火山 Coding Plan、智谱 GLM、Kimi、Z.ai。按 Key 外观自动缩小尝试范围（UUID 格式走火山、带点格式走智谱）；`sk-` 开头的 Key 各平台长得一样，无法从外观区分，会自动逐个尝试。

### API 引擎稳定性

- **火山接口/模型自动匹配**：地址×模型组合并行探测（一轮完成，不串行等待），成功的组合记住后秒连；组合失效自动重新匹配
- 单次请求超时 120 秒；**任何一题失败立即暂停**整个队列（不做多次重试），原因写入日志
- 完成报告显示「填写 X 题 / 失败 Y 题」，失败的题目行点击可单题重答
- 修复后点「开始」整页重跑：已成功的题命中答案缓存，秒填不耗额度

### 豆包 API 免费路径

火山引擎控制台（console.volcengine.com/ark）→ 开通方舟 → 领取免费额度模型（如 doubao-lite 系列）→ 创建 API Key。把 Key 粘贴到面板保存即可，自动识别会匹配到火山地址。

## 每次更新代码后

- 手动：`chrome://extensions` 点插件卡片上的 ↻ 重新加载 + 刷新页面 F5
- 或热重载：`node tools/watch.mjs`（代码一变插件自动重载，页面仍需 F5）
- 或点「更新」：设置页/面板发现新版后点「更新」，本机脚本自动下载替换（见下文「自动更新（GitHub 版）」）

## 更新检查

自动检查在 **设置页**：打开「检测更新」分区时自动对比 **GitHub 仓库** 上的最新版本（先读 GitHub API 拿实时版本号，失败回退 jsDelivr CDN 镜像，再回退官方 raw——大陆网络下 raw.githubusercontent.com 常被 DNS 劫持、jsDelivr 对 @master 最多缓存 12 小时；结果缓存 1 小时，失败静默不打扰）。

**更新永不强制**：不自动安装、不阻断使用，你可以一直用当前版本；需要时点「立即检查」绕过缓存，或从设置页/面板提示行的 GitHub 入口下载最新代码，再按「每次更新代码后」的步骤手动重载即可（插件自身在沙箱里不能替换文件；一键替换由本机脚本完成——见下文「自动更新（GitHub 版）」）。

面板只在**功能更新**（版本号第二段变化，如 0.4.x → 0.5.0）时显示提示行提醒；只有末位补丁号变化的修复更新不打扰面板，只在设置页安静显示。

## 自动更新（GitHub 版）

浏览器沙箱里的插件不能改写自身文件，自动替换由**本机脚本**完成，且**只在用户点了「更新」之后才执行**——不点不装、不常驻、不自动定时：

1. 首次安装（每台机器一次）：在插件目录运行 `node tools/install-native-host.mjs <插件目录>`（Edge 加第二个参数 `edge`）。脚本会写好原生消息宿主清单与注册表；扩展 ID 按插件目录自动推算并写进 `.crinfo`（未打包扩展的 ID 由目录路径决定），若与 `chrome://extensions` 里显示的不一致，把那个 ID 填进 `.crinfo` 后重跑一次即可。没装宿主就点「更新」会提示**「更新宿主未安装或已失效」**（浏览器原始报错是 `Specified native messaging host not found`，注册表键失效时是 `... is forbidden`），按上面跑一次安装脚本即可，装完要重开浏览器。
2. 日常使用：设置页「检测更新」发现新版 → 出现「更新」按钮 → 点它。浏览器经原生消息宿主拉起 `tools/native-host.mjs` → 调用 `tools/autoupdate.mjs` 同步一轮：先把 master 钉到当前 commit（GitHub 的提交订阅源，网页、不占 API 配额）→ 版本号、文件清单、文件本身整轮都从那个**不可变快照**读（清单走 jsDelivr 的接口，每一项带 sha256）→ 把扩展文件全部下载到 `.update-stage/` 暂存（任何一个下载失败、或下载到的字节与清单里的 sha256 不符，就整轮放弃、旧文件原封不动）→ 全部成功后覆盖/新增文件、删除远端已移除的文件 → 写 `hot-reload.json` 触发插件后台自动重载。**一轮更新只用一个快照**：这样即便 GitHub API 配额中途用尽、或 CDN 尚未同步完，也只会「这轮没更成」，不会装出半新半旧却报「已更新到 vX」的版本。钉不住 commit 时退回 GitHub API / jsDelivr `@master`，此时靠装前两道校验兜底：核对暂存下来的 manifest 是不是要装的那一版、manifest 声明的脚本是否都下齐了，对不上就整轮放弃并提示稍后重试。插件目录由宿主自己定位（它就在插件根的 tools/ 下），所以换电脑、换目录都不用改代码。
3. 更新完成后插件自动重载，**作业页面仍需 F5** 让内容脚本生效；面板提示行同样只在功能更新（次版本号变化）时出现「更新」按钮。

脚本更新扩展实际加载的文件（manifest.json、background/、content/、options/、icons/、settings.html、settings.js）**以及 tools/ 里的更新脚本本身**（`tools/*.mjs`）——更新逻辑改一次就跟着版本走到每台机器，不用再回每台机器手抄，大小更新都能一路自动。只认远端清单列出的文件，所以本机私有的启动器 `tools/native-host.exe`、本地测试脚本（如 `tools/test-autoupdate.mjs`）不会被碰；README、LICENSE、package.json 等也不在更新范围。**唯一仍需每台机器手动一次的**是 `install-native-host.mjs` 生成的启动器与注册表：启动器把浏览器和 node 接起来，它自己不能被正在运行的更新器替换，所以某版若改动了启动器的编译方式（少见），那台机器才需要重拉仓库并重跑一次安装脚本。宿主只接受已注册的那个扩展的请求，不监听端口。也可以手动同步一轮（不经过浏览器）：`node tools/autoupdate.mjs <插件目录>`。

## 设置页

面板标题栏点「设置」打开独立设置页（独立标签页，左侧边栏切换：记忆 / 诊断 / 检测更新；当前分区记在地址栏，刷新与前进后退都停在原分区；窄窗口自动折叠成顶部导航）：

- **记忆**：顶部显示当前已记住的答题记忆条数，下面是清除 AI 答题记忆（缓存）。首次清除有确认，可勾选「以后不再提示」直接清除
- **诊断**：把你最近访问过的那个网页结构导出为 HTML 文件（先在作业页停留，再回到这里导出；站点适配失败时发给开发者排查）
- **检测更新**：显示当前版本与最新版本；打开本分区自动检查一次，「立即检查」绕过 1 小时缓存；发现新版出现「更新」按钮，点了才自动下载替换（首次使用需先运行一次 install-native-host.mjs，见「自动更新（GitHub 版）」）；检查失败可直接重试。更新不强制，可继续用当前版本

## 界面

- 视觉按 Pixso 设计稿实现
- **API 配置收纳为可折叠抽屉**：API 引擎下「接口 与 API Key」块可点标题折叠/展开；折叠状态记忆在本机；豆包桥接下整块消失。非 API 模式与折叠模式面板同尺寸（72vh），展开抽屉时面板整体适当变高（至多近全屏），多出的空间留给题目列表和日志，背景光晕固定半径不随高度拉伸：**无图标、纯文字**风格——浅色渐变卡片面板、蓝底白字 ⚡ 悬浮球、标题栏文字按钮（展开/设置/收起）、题目行尾文字状态（待机/获取中/填入/改对/保留/失败）
- **面板和悬浮球都可拖动**：面板按住标题栏拖到任意位置（别挡住题目/提交按钮）；⚡ 悬浮球也能拖（拖动和点击自动区分，拖了就不会误开面板）
- **提示气泡在面板内自绘**：按钮/列表行的说明文字是自绘圆角气泡（鼠标悬停与键盘聚焦都会出现，跟随目标并在屏幕内收边），不再用浏览器原生的 `title` 系统气泡
- **浏览器原生控件表面已统一主题**：选中文字、输入光标、键盘焦点环、滚动条、复选框都按面板的蓝色主题着色，Windows 深色模式下也不出现原生的黑边/黄底控件
- **「引擎」和「接口类型」是自绘下拉**（`content/homework/dropdown.js`，面板与设置页共用）：原生 select 的展开层是系统窗口、样式改不到，所以弹层由插件自己画——每项两行（名称 + 说明），选中的那项是淡蓝底 + 左侧蓝条、鼠标悬停是中性灰底（两者一眼分得开）；支持 ↑↓ 移动、Enter/Space 选中、Esc 关闭、点击控件外关闭，焦点始终留在控件上
- **API Key 输入框的标签不带底色**：输入框有内容或获得焦点时，标签浮到输入框上方（原先压在边框上且垫了一块白底，会盖住边框）
- 位置**按网站记住**（刷新、下次打开还在原地），双击面板标题栏一键复位到右下角默认位置
- **清除记忆**：删除 AI 历史答题缓存（同一题反复答错、错误答案被缓存复用时用）。入口在设置页「记忆」（点面板标题栏「设置」打开）；首次清除弹确认，可勾选「以后不再提示」直接清除；清除只删答案缓存，不动页面已填答案、API Key、接口配置；下一轮所有题目重新问 AI（重新耗额度）
- 拖动时自动限制在屏幕范围内，不会拖丢

## 提交与重跑

- **插件只填写、永不自动提交**——检查无误后请自行点提交（此设计无开关，防止误交）
- **逐题核对**：每道题先读页面状态 → 没写直接写；写了就与参考答案（缓存）比对，写对跳过、写错自动改写；页面状态读不出来时视为没写直接写（重填有防取消保护）。比对不消耗引擎调用
- 注意：超星会把已填答案从服务器恢复到页面（重新打开作业页时选项可能自动带出旧答案），插件会照常核对填写，不影响结果

### 火山 Key 免配置细节

- 保存火山 Key（UUID 格式）后自动探测：同时尝试 Coding 套餐地址（`/api/coding`）与按量地址（`/api/v3`）
- **模型名自动匹配**：预填模型不存在（404）时，引擎自动遍历候选模型（doubao-seed-code / doubao-seed-2-0-code / kimi-k2-thinking / deepseek-v3-2 / glm-4-7），成功的自动记住（按 Key 尾号绑定，之后秒连）
- 组合失效（401/403/404）自动重新匹配一次
- 也可以手动指定：接口类型选「OpenAI 兼容」或「Anthropic」，地址和模型照抄套餐「使用配置」页
- **Key 自动清理**：保存 Key 时自动去除混入的中文/全角符号/空格（这类字符会让请求根本发不出去），并提示清理后的尾号供核对；鉴权失败(401)的报错会显示当前接口地址，方便发现"Key 与接口不匹配"

## 目录结构

```
manifest.json              # MV3 配置
background/
  service-worker.js        # 队列、缓存、引擎路由、热重载
  engines/
    engine.js              # 共享：Prompt 构建 / 答案解析 / 哈希
    api-engine.js          # OpenAI 兼容 API 引擎
    bridge-engine.js       # 豆包桥接（M2）
content/
  homework/
    dropdown.js            # 自绘下拉（引擎 / 接口类型，面板与设置页共用）
    extractor.js           # 题目提取（通用启发式）
    filler.js              # 答案填写（React/Vue 兼容）
    panel.js               # 悬浮面板（Shadow DOM）
    content.js             # 入口
  doubao/doubao-bridge.js  # 豆包页桥接脚本（M2）
options/                   # 设置页（API / 豆包桥接）
settings.html / settings.js  # 工具设置页（侧边栏：记忆 / 诊断 / 检测更新）
tools/watch.mjs            # 热重载监听
tools/autoupdate.mjs       # GitHub 版自动更新（检查→下载→替换→热重载；点「更新」时由浏览器拉起，随版本一起自动更新）
tools/native-host.mjs      # 原生消息宿主（浏览器 ↔ autoupdate.mjs 的桥梁，随版本一起自动更新）
tools/install-native-host.mjs # 一次性安装：注册原生宿主（注册表+清单；改到它时需在本机重跑一次）
tools/native-host.exe      # 安装脚本本机编译的启动器（不入库、不自动更新）
```

- 桥接引擎通过豆包网页对话作答，请保持豆包标签页处于可正常对话的状态；已内置随机延迟缓解风控风险，建议仅自用
- 建议用于练习自测与答案核对场景，留意所在学校/平台的使用规则
